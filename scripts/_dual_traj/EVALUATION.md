# Trio evaluation

Run from the LTX-2 repository with its `.venv`:

```bash
.venv/bin/python scripts/_dual_traj/evaluate_trio.py \
  --source-video /path/source.mp4 \
  --reference-image /path/edited_first_frame.png \
  --routing-mask /path/stage2_masks \
  --reference-mask /path/reference_mask.png \
  --image-video /path/image_branch/output.mp4 \
  --video-video /path/video_branch/output.mp4 \
  --dual-video /path/dual_partition/output.mp4 \
  --subject-concept "woman" \
  --output-dir /path/evaluation
```

The output videos must share resolution, FPS, and frame count. The source must
share FPS and frame count; its spatial dimensions may differ. Source and reference
are transformed with the inference resize-and-center-crop operation. Draw masks
in their original image coordinate system or on the output canvas. A static mask
is repeated over time. PNG mask directories must contain exactly one image per
video frame. The optional reference mask defaults to the routing mask's frame 0.

The `image` label denotes the image + IC-LoRA Stage-2 branch; `video` denotes
image + source video + IC-LoRA; `dual` denotes the region-selective output.
Provide `--source-silhouette-mask`, `--image-silhouette-mask`,
`--video-silhouette-mask`, and `--dual-silhouette-mask` to reuse externally
computed silhouettes. These are separate from the shared routing mask. Missing
silhouettes are generated by the deployed SAM3 tool using the shared concept.
Existing evaluator-generated SAM3 results are reused only if their input hash,
concept, and frame count match; stale results fail with a clear error.

DINOv2 uses the existing local register ViT-B/14 repository/checkpoint. Override
with `--dino-repository` and `--dino-checkpoint`. RAFT-Large uses torchvision's
default pretrained weights (downloaded on first use), or `--raft-checkpoint` for
an offline state dict with the same architecture. SAM3 paths can be overridden
with `--sam3-python` and `--sam3-tool`. `--device cpu` selects CPU for DINO/RAFT;
the external SAM3 deployment still requires its GPU environment.

Use `--max-frames 2` for an explicitly recorded prefix smoke test. SAM3 still
segments the complete input video when generation is needed. Reused silhouettes
are user inputs; a supplied mask without a SAM3 manifest has no verified model
provenance. The supplied static-mask option is useful for numerical tests but
does not measure subject shape unless it actually represents the silhouette.

Results include per-frame appearance/IoU, per-pair flow, summary tables, timeline
plots, a Markdown report, and a provenance manifest. Source flows are saved under
`source_flows/` for reuse across branches within this invocation. GPU models are
loaded sequentially. Full pixel mask sequences reside on CPU; frame and flow
decoding is incremental. A new evaluation invocation recomputes DINO/RAFT scores.

All-frame and frame-17-onward means/std/counts are reported. Undefined empty
supports are excluded, with empty silhouettes and coverage recorded. DINO is a
regional feature score sensitive to pose and shape as well as appearance. RAFT
measures disagreement between estimated flows in output-pixel units. Expected
rankings are hypotheses, never constraints applied to the measurements.

Numerical tests:

```bash
.venv/bin/python -m pytest tests/test_evaluate_trio.py -q
```
